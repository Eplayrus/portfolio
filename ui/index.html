UI kit на чистом CSS

Компоненты: кнопки, инпуты, модалки, dropdown, tabs, toast, tooltip. CSS-переменные как токены. BEM для компонентов + небольшие utility.

Доступность
Везде есть focus ring, aria-атрибуты, и нормальное поведение по клавиатуре.

Токены и тема через data-theme

  --bg: #0b0c10;
  --panel: #12141b;
  --text: #e9edf5;
  --muted: #9aa4b2;

  --primary: #7c5cff;
  --success: #22c55e;
  --danger: #ef4444;
  --warning: #f59e0b;

  --radius: 14px;
  --ring: 0 0 0 3px color-mix(in srgb, var(--primary) 35%, transparent);
}

[data-theme="light"]{
  --bg: #f6f7fb;
  --panel: #ffffff;
  --text: #111827;
  --muted: #6b7280;
}

Buttons

Варианты

Loading

aria-busy

Loading делается через [data-loading="true"] + псевдо-спиннер.

Пример кнопок 
<button class="ui-btn ui-btn--primary">Primary</button>
<button class="ui-btn ui-btn--secondary ui-btn--sm">Small</button>
<button class="ui-btn" disabled>Disabled</button>

<button class="ui-btn ui-btn--primary"
        data-loading="true" aria-busy="true">
  Сохранение
</button>
